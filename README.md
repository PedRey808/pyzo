# Movie Library (Личная кинотека)

**Автор:** Изгагин Матвей

## Описание
GUI-приложение на базе `tkinter` для ведения личного каталога фильмов. Позволяет добавлять новые фильмы с указанием названия, жанра, года выпуска и рейтинга (от 0 до 10). Данные автоматически сохраняются в формате JSON. В приложении реализована таблица (Treeview) с функцией мгновенной фильтрации списка по жанру и году.

Дополнительно в проекте интегрирована работа с открытым API и библиотекой `random` для вывода случайных цитат.

## Инструкция по запуску
1. Установите необходимые библиотеки (приложение использует встроенный `tkinter`, но для работы с API нужен `requests`):
   `pip install requests`
2. Запустите главный файл приложения:
   `python main.py`

## Примеры использования (Тестирование)
Для проверки логики приложения и валидации данных написаны unit-тесты (позитивные, негативные и граничные случаи). 
Запуск тестов осуществляется командой:
`python -m unittest test_main.py`
