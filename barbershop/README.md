# КЛИНОК — сайт барбершопа (motion design)

Одностраничный сайт вымышленного барбершопа «КЛИНОК» (Санкт-Петербург, ул. Рубинштейна, 17).
Чистые HTML/CSS/JS, без сборки и зависимостей (только шрифты Google Fonts: Unbounded + Manrope).

## Запуск
Откройте `index.html` в браузере или поднимите локальный сервер:

```bash
cd barbershop
python -m http.server 8000
# http://localhost:8000
```

## Что внутри
- **Прелоадер** со счётчиком 0–100 % и «щёлкающими» ножницами, шторка-переход.
- **Hero**: побуквенное появление заголовка, анимированный барбер-пол, вращающийся бейдж «Записаться», параллакс фигур за курсором.
- **Бегущая строка**, которая наклоняется в зависимости от скорости скролла.
- **Текст «О нас»** подсвечивается по словам при прокрутке, счётчики цифр.
- **Прайс** с фильтром по категориям и заливкой строк при наведении.
- **«Ритуал в 5 шагов»** — горизонтальный скролл с закреплённой секцией (на мобильных — свайп-лента со scroll-snap).
- **Мастера** — SVG-портреты, которые «рисуются» линией, 3D-наклон карточек, морфинг фона.
- **Отзывы** — слайдер с автопрокруткой, свайпом и drag.
- **Онлайн-запись** — выбор услуги, мастера, дня и времени, маска телефона, валидация и анимация успеха.
- **Карта-схема** с анимированным маршрутом от метро.
- Кастомный курсор и «магнитные» кнопки на десктопе.

## Мобильная версия
- Полноэкранное меню с круговым раскрытием и поочерёдным появлением пунктов.
- Плавающая кнопка «Записаться», которая прячется у формы записи.
- Адаптивные сетки от 320 px, `safe-area` для iPhone, без горизонтального скролла.
- Учитывается `prefers-reduced-motion`: анимации отключаются для тех, кому они мешают.

Все данные (адрес, цены, мастера, отзывы, телефон) вымышлены.
