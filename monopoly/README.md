# 🎩 Магнат — онлайн-игра в жанре «экономическая монополия»

Браузерная игра на ПК и телефоне, от 2 до 8 игроков (люди + боты). Запустить можно двумя способами:
* **свой сервер** `server.js` на телефоне (Termux) или компьютере. Это надёжнее всего;
* **без сервера**: выложить `index.html` на любой хостинг. Тогда игроки соединяются напрямую через WebRTC
  (библиотека PeerJS и её бесплатный публичный брокер).

## 📱 Свой сервер на телефоне через Termux (самый простой способ)
Нужны два файла в одной папке: `index.html` и `server.js`. Других зависимостей нет.

1. Установите **Termux** (лучше из F-Droid) и выполните в нём:
   ```sh
   pkg update && pkg install nodejs
   termux-setup-storage          # дать доступ к папке «Загрузки»
   ```
2. Положите `index.html` и `server.js` в «Загрузки» (например, в папку `magnat`) и запустите:
   ```sh
   cd ~/storage/downloads/magnat
   termux-wake-lock              # чтобы Android не усыпил сервер
   node server.js
   ```
3. Сервер покажет адреса:
   ```
   На этом устройстве:   http://localhost:8080
   Для друзей (Wi-Fi):   http://192.168.1.23:8080
   ```
   Вы сами открываете `http://localhost:8080` в браузере телефона, а друзья открывают второй адрес.
   Друзья должны быть **в той же Wi-Fi сети** или подключены к **точке доступа вашего телефона**
   (раздача интернета). В этом случае интернет вообще не нужен.
4. Нажмите «Создать комнату». Друзья увидят её в списке «Открытые комнаты» или войдут по коду.

**Играть через интернет** (друзья далеко). Нужен туннель, который даёт публичную ссылку:
* `pkg install cloudflared`, затем `cloudflared tunnel --url http://localhost:8080`
  и отправьте друзьям ссылку вида `https://….trycloudflare.com`;
* или без установки: `pkg install openssh`, затем `ssh -R 80:localhost:8080 nokey@localhost.run`.

Туннель запускайте во второй вкладке Termux (свайп слева → New session), пока работает `node server.js`.

Полезное:
* Другой порт: `PORT=3000 node server.js`. Остановить сервер: `Ctrl+C`.
* Партии сохраняются в `magnat-rooms.json`. После перезапуска сервера игра продолжится, игроки переподключатся сами.
* Сервер работает и на компьютере (Windows/Mac/Linux): установите Node.js и выполните `node server.js`.

## Как играть с друзьями без своего сервера
1. Выложите `index.html` в интернет, чтобы его открывали все игроки. Проще всего через GitHub Pages:
   *Settings → Pages → Deploy from a branch* → выбрать ветку, папка `/ (root)`.
   Игра будет по адресу `https://<ник>.github.io/<репозиторий>/monopoly/`.
   Подойдёт любой хостинг статических файлов (Netlify, Vercel и т. п.).
2. Один игрок нажимает **«Создать комнату»** и получает код из 5 символов.
   Он же отправляет друзьям ссылку-приглашение кнопкой 🔗.
3. Остальные вводят код (или открывают ссылку) и нажимают **«Войти»**.
4. Создатель комнаты может добавить ботов, выбрать стартовый капитал и нажать **«Начать игру»**.

**Без интернета:** кнопка «Играть с ботами» запускает партию против трёх ботов прямо в браузере.

## Важно
* Партию держит браузер создателя комнаты. Пусть он не закрывает вкладку (лучше играть с ПК).
* Если вкладку закрыли или связь пропала, игра сохранилась: откройте страницу снова и нажмите
  «Продолжить» / «Вернуться». Игроки подключатся автоматически.
* Если игрок отключился больше чем на 30 секунд, за него ходит автопилот, пока он не вернётся.

## Правила
* Каждый проход через «Старт»: +2 000 ₽. Стартовый капитал: 15 000 ₽ (можно изменить).
* Свободный город, порт или предприятие можно купить. Владелец получает аренду.
* Собрали все города одного цвета: аренда удваивается, можно строить до 4 домов и отель (строить равномерно).
* Порты: аренда 250 / 500 / 1 000 / 2 000 ₽. Предприятия: сумма кубиков × 40 (за оба × 100).
* Дубль: ещё один бросок. Три дубля подряд: тюрьма. Выйти можно дублем, штрафом 500 ₽ или картой освобождения.
* Карты «Удача» и «Казна» дают бонусы, штрафы и перемещения.
* Если не хватает денег, продавайте дома, закладывайте имущество или договаривайтесь о сделках. Иначе банкротство.
* Сделки: обмен городами и деньгами с любым игроком (вкладка «Сделки»). Боты тоже торгуют.
* Побеждает последний оставшийся в игре.

## Свой сервер PeerJS (необязательно)
Если публичный брокер недоступен, запустите свой (`npx peer --port 9000`) и откройте игру с параметрами
`?peerHost=ваш.хост&peerPort=9000&peerSecure=0`.
