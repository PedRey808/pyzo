# 🎩 Магнат — онлайн-игра в жанре «экономическая монополия»

Браузерная игра на ПК и телефоне, от 2 до 8 игроков (люди + боты). Запустить можно двумя способами:
* **свой сервер** `server.js` на телефоне (Termux) или компьютере. Это надёжнее всего;
* **без сервера**: выложить `index.html` на любой хостинг. Тогда игроки соединяются напрямую через WebRTC
  (библиотека PeerJS и её бесплатный публичный брокер).

## 📲 Приложение для Android (APK)
Скачать последнюю версию:
**https://github.com/PedRey808/pyzo/releases/download/apk-latest/Magnat.apk**

1. Откройте ссылку на телефоне, скачайте `Magnat.apk` и откройте файл.
2. Разрешите установку из этого источника (браузер или «Файлы») и нажмите «Установить».
3. Все игроки ставят приложение. Один нажимает «Создать комнату», затем «📤 Пригласить друзей»
   и отправляет код в мессенджер. Остальные нажимают «Войти» и вводят код.

Wi-Fi у игроков может быть разный, подойдёт и мобильный интернет: телефоны соединяются напрямую через интернет (WebRTC).
Партия идёт на телефоне создателя комнаты, поэтому ему **нельзя закрывать приложение и надолго его сворачивать**.
Если приложение закрылось, откройте его снова и нажмите «Продолжить»: друзья переподключатся сами.

APK собирается автоматически (GitHub Actions, `.github/workflows/android-apk.yml`) при каждом изменении игры.
Исходники приложения лежат в папке `android/`.

## 💻 Программа для Windows (EXE)
Скачать: **https://github.com/PedRey808/pyzo/releases/download/pc-latest/Magnat.exe**

Устанавливать не нужно: скачайте и запустите. Первый запуск занимает несколько секунд.
Windows может показать «Система Windows защитила ваш компьютер»: нажмите **«Подробнее» → «Выполнить в любом случае»**
(у программы нет платной цифровой подписи). Если появится вопрос брандмауэра, разрешите доступ.

Игра по сети работает так же, как в APK: через интернет по коду комнаты, из любой точки.
ПК и телефоны с APK играют вместе в одной комнате. Кнопка «📋 Скопировать приглашение» копирует код комнаты
и ссылки на скачивание, их можно сразу отправить друзьям.
Клавиши: **F11** — полный экран, **Ctrl+R** — перезагрузить.

Исходники программы лежат в папке `desktop/` (Electron). Запустить из исходников: `cd desktop && npm install && npm start`.

## 🍏 iPhone и iPad (IPA)
Скачать: **https://github.com/PedRey808/pyzo/releases/download/ios-latest/Magnat.ipa** (iOS 15 и новее)

Apple не разрешает ставить приложения не из App Store просто так. Файл нужно подписать своим Apple ID
с помощью программы на компьютере. Проще всего через **Sideloadly** (бесплатно, Windows и Mac):
1. Установите Sideloadly с сайта sideloadly.io и iTunes (на Windows, с сайта Apple, не из Microsoft Store).
2. Подключите iPhone к компьютеру кабелем и нажмите на телефоне «Доверять».
3. Перетащите `Magnat.ipa` в окно Sideloadly, введите свой Apple ID и нажмите **Start**.
4. На iPhone: **Настройки → Основные → VPN и управление устройством** → ваш Apple ID → **Доверять**.
5. Начиная с iOS 16: **Настройки → Конфиденциальность и безопасность → Режим разработчика** → включить и перезагрузить телефон.

С бесплатным Apple ID приложение работает **7 дней**, потом повторите шаг 3, игры не пропадут.
Альтернатива — **AltStore** (altstore.io): он сам продлевает подпись по Wi-Fi.

Игра по сети такая же, как на Android и ПК: по коду комнаты через интернет, все устройства в одной комнате.
Если вы создатель комнаты на iPhone, не сворачивайте приложение: iOS быстро приостанавливает свёрнутые программы.

Исходники приложения лежат в папке `ios/` (Swift, WKWebView). Собирается автоматически в GitHub Actions на macOS.

## 📱 Свой сервер на телефоне через Termux (самый простой способ)
Нужны два файла в одной папке: `index.html` и `server.js`. Других зависимостей нет.

1. Установите **Termux** (лучше из F-Droid) и выполните в нём:
   ```sh
   pkg update && pkg install nodejs
   termux-setup-storage          # дать доступ к папке «Загрузки»
   ```
2. Положите `index.html` и `server.js` в «Загрузки» (например, в папку `magnat`) и запустите:
   ```sh
   cd ~/storage/downloads/magnat
   termux-wake-lock              # чтобы Android не усыпил сервер
   node server.js
   ```
3. Сервер покажет адреса:
   ```
   На этом устройстве:   http://localhost:8080
   Для друзей (Wi-Fi):   http://192.168.1.23:8080
   ```
   Вы сами открываете `http://localhost:8080` в браузере телефона, а друзья открывают второй адрес.
   Друзья должны быть **в той же Wi-Fi сети** или подключены к **точке доступа вашего телефона**
   (раздача интернета). В этом случае интернет вообще не нужен.
4. Нажмите «Создать комнату». Друзья увидят её в списке «Открытые комнаты» или войдут по коду.

**Играть через интернет** (друзья далеко). Нужен туннель, который даёт публичную ссылку:
* `pkg install cloudflared`, затем `cloudflared tunnel --url http://localhost:8080`
  и отправьте друзьям ссылку вида `https://….trycloudflare.com`;
* или без установки: `pkg install openssh`, затем `ssh -R 80:localhost:8080 nokey@localhost.run`.

Туннель запускайте во второй вкладке Termux (свайп слева → New session), пока работает `node server.js`.

Полезное:
* Другой порт: `PORT=3000 node server.js`. Остановить сервер: `Ctrl+C`.
* Партии сохраняются в `magnat-rooms.json`. После перезапуска сервера игра продолжится, игроки переподключатся сами.
* Сервер работает и на компьютере (Windows/Mac/Linux): установите Node.js и выполните `node server.js`.

## 💻 На компьютере
**Если сервер уже запущен на телефоне** (Termux), на ПК ничего ставить не нужно. Откройте в браузере адрес
из строки «Для друзей (Wi-Fi)», например `http://192.168.1.23:8080`. ПК должен быть в той же Wi-Fi сети
или подключён к точке доступа телефона.

**Запустить сервер на самом ПК (Windows):**
1. Установите Node.js с https://nodejs.org (кнопка LTS, всё по умолчанию).
2. Распакуйте архив и дважды щёлкните `Запуск-Windows.bat`. Откроется окно сервера и браузер с игрой.
3. Если Windows спросит про брандмауэр, нажмите «Разрешить доступ» (частные сети).
4. Друзья с телефонов и других ПК в той же Wi-Fi открывают адрес «Для друзей (Wi-Fi)» из окна сервера.

На Mac/Linux: `sh start.sh` в папке игры.

**Просто поиграть одному с ботами:** дважды щёлкните `index.html` и нажмите «Играть с ботами».

## Как играть с друзьями без своего сервера
1. Выложите `index.html` в интернет, чтобы его открывали все игроки. Проще всего через GitHub Pages:
   *Settings → Pages → Deploy from a branch* → выбрать ветку, папка `/ (root)`.
   Игра будет по адресу `https://<ник>.github.io/<репозиторий>/monopoly/`.
   Подойдёт любой хостинг статических файлов (Netlify, Vercel и т. п.).
2. Один игрок нажимает **«Создать комнату»** и получает код из 5 символов.
   Он же отправляет друзьям ссылку-приглашение кнопкой 🔗.
3. Остальные вводят код (или открывают ссылку) и нажимают **«Войти»**.
4. Создатель комнаты может добавить ботов, выбрать стартовый капитал и нажать **«Начать игру»**.

**Без интернета:** кнопка «Играть с ботами» запускает партию против трёх ботов прямо в браузере.

## Важно
* Партию держит браузер создателя комнаты. Пусть он не закрывает вкладку (лучше играть с ПК).
* Если вкладку закрыли или связь пропала, игра сохранилась: откройте страницу снова и нажмите
  «Продолжить» / «Вернуться». Игроки подключатся автоматически.
* Если игрок отключился больше чем на 30 секунд, за него ходит автопилот, пока он не вернётся.

## Правила
* Каждый проход через «Старт»: +2 000 ₽. Стартовый капитал: 15 000 ₽ (можно изменить).
* Свободный город, порт или предприятие можно купить. Владелец получает аренду.
* Собрали все города одного цвета: аренда удваивается, можно строить до 4 домов и отель (строить равномерно).
* Порты: аренда 250 / 500 / 1 000 / 2 000 ₽. Предприятия: сумма кубиков × 40 (за оба × 100).
* Дубль: ещё один бросок. Три дубля подряд: тюрьма. Выйти можно дублем, штрафом 500 ₽ или картой освобождения.
* Карты «Удача» и «Казна» дают бонусы, штрафы и перемещения.
* Если не хватает денег, продавайте дома, закладывайте имущество или договаривайтесь о сделках. Иначе банкротство.
* Сделки: обмен городами и деньгами с любым игроком (вкладка «Сделки»). Боты тоже торгуют.
* **Аукцион при банкротстве:** всё имущество банкрота (без домов и залога) по очереди уходит с молотка.
  Ставки делают все игроки, боты тоже. На лот даётся 20 секунд, и каждая ставка продлевает таймер минимум до 8 секунд.
  Лот достаётся тому, чья ставка последней лидирует. Деньги получает игрок, которому банкрот задолжал
  (если долг был банку, деньги уходят банку). Если никто не сделал ставку, город остаётся у банка.
* Побеждает последний оставшийся в игре.

## Свой сервер PeerJS (необязательно)
Если публичный брокер недоступен, запустите свой (`npx peer --port 9000`) и откройте игру с параметрами
`?peerHost=ваш.хост&peerPort=9000&peerSecure=0`.
