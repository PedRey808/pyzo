# MusicHub — один плеер для Яндекс Музыки, SoundCloud, Spotify и YouTube

Ищет музыку сразу во всех сервисах, играет её и сохраняет любой трек файлом **mp3** на компьютер
(и на телефон). Работает на ПК в браузере или отдельном окне, а на телефоне — через браузер,
приложение можно «установить» на главный экран.

## Что умеет
- Поиск одновременно по Яндекс Музыке, SoundCloud, Spotify и YouTube (или по одному источнику).
- Вставьте в поиск ссылку на **трек / альбом / плейлист Spotify** — получите весь список.
- Плеер с очередью, перемоткой, управлением с экрана блокировки телефона.
- Кнопка **⬇** — сохранить трек в папку на компьютере (по умолчанию `~/Music/MusicHub`),
  название и исполнитель прописываются в теги.
- Кнопка **📱** (видна при открытии с телефона) — скачать файл прямо на телефон.
- Вкладка «Скачанное» — слушать сохранённые треки без интернета до сервисов.

### Как это работает с каждым сервисом
| Сервис | Поиск | Звук и скачивание |
|---|---|---|
| Яндекс Музыка | ✅ (нужен токен) | ✅ mp3 до 320 кбит/с, полные треки — с подпиской Плюс |
| SoundCloud | ✅ без настройки | ✅; если трек защищён DRM или доступен только отрывок (значок «🔒 замена»), звук автоматически берётся из Яндекс Музыки / другой загрузки / YouTube |
| Spotify | ✅ (вход через Spotify: поиск, «Любимые», плейлисты) | звук Spotify защищён DRM, поэтому тот же трек автоматически находится в Яндекс Музыке → SoundCloud → YouTube |
| YouTube | ✅ без настройки | ✅ |
| VK Музыка | — | пока нет: у VK закрыт API для музыки, сторонние способы ломаются и могут привести к блокировке аккаунта |

## Скачать готовое приложение
Готовые файлы собираются автоматически и лежат на странице релиза **«MusicHub — последняя сборка»**
(в репозитории: Releases → `musichub-latest`):

- **MusicHub.exe** — Windows 10/11. Скачайте и запустите, откроется окно плеера.
  Если Windows покажет «Система Windows защитила ваш компьютер», нажмите «Подробнее» →
  «Выполнить в любом случае»: у программы нет платной цифровой подписи.
  Треки сохраняются в `Музыка\MusicHub`.
- **MusicHub.apk** — Android 7 и новее, 64-битный телефон (почти все с 2017 года). Откройте файл на телефоне и разрешите установку
  «из этого источника». Приложение работает **само по себе, компьютер не нужен**.
  Кнопка ⬇ сохраняет трек в папку «Музыка/MusicHub» на телефоне.
  Музыка продолжает играть со свёрнутым приложением (в шторке висит уведомление MusicHub).

> APK подписан отладочным ключом, который меняется от сборки к сборке. Если новая версия не
> ставится поверх старой — удалите старую (настройки и токены придётся ввести заново).

## Запуск из исходников (Windows / macOS / Linux)
1. Установите [Python 3.10+](https://www.python.org/downloads/) (на Windows отметьте «Add Python to PATH»).
2. По желанию установите **ffmpeg** — тогда всё будет сохраняться в mp3
   (без него треки сохраняются в исходном формате: mp3, m4a или aac):
   - Windows: `winget install ffmpeg`
   - macOS: `brew install ffmpeg`
   - Linux: `sudo apt install ffmpeg`
3. В папке `music_player`:
   ```
   pip install -r requirements.txt
   python run.py
   ```
   Откроется браузер с плеером. Для отдельного окна: `pip install pywebview` и `python run.py --window`.

## Открыть плеер с компьютера на телефоне (без APK)
1. Запустите на компьютере: `python run.py --lan --password придумайте_пароль`
   (или `MusicHub.exe --lan --password придумайте_пароль` — можно вписать в ярлык).
2. В консоли появится адрес вида `http://192.168.1.5:8765` — откройте его на телефоне
   (телефон в той же Wi-Fi сети). Логин любой, пароль — ваш.
3. В меню браузера выберите «Добавить на главный экран».

Чтобы пользоваться с телефона **вне дома**, запустите MusicHub на любом сервере (VPS) или
домашнем ПК с внешним адресом — телефон будет ходить только на ваш сервер, а сервер уже к сервисам.

## Настройки (вкладка «Настройки»)
- **Яндекс Музыка — кнопка «Войти через Яндекс».** В приложении для Android и в MusicHub.exe
  откроется страница входа Яндекса. После входа токен подхватится сам, а в настройках появится
  «Вы вошли как … · Плюс ✓». В обычном браузере (`python run.py`) откроется новая вкладка:
  после входа скопируйте адрес страницы, на которую вас перекинуло (в нём есть `access_token=`),
  и вставьте его в поле «Токен или адрес страницы после входа». Подходит и сам токен (`y0_…`).
  Если адрес сразу меняется и токен не виден: перед открытием ссылки нажмите F12 → вкладка
  Network → галочка «Preserve log», войдите и найдите строку с `access_token` в списке запросов.
  Токен хранится только у вас: `~/.musichub/settings.json` на ПК, память приложения на телефоне.
- **Spotify — кнопка «Войти через Spotify».** Один раз создайте своё приложение Spotify
  (в настройках MusicHub есть пошаговая инструкция):
  1. https://developer.spotify.com/dashboard → **Create app**;
  2. в **Redirect URIs** добавьте `http://127.0.0.1:8765/api/spotify/callback`, отметьте **Web API**, сохраните;
  3. скопируйте **Client ID** в настройки MusicHub, нажмите «Сохранить», затем «Войти через Spotify».

  После входа на вкладке «Поиск» появятся кнопки «❤ Любимые в Spotify» и «Мои плейлисты Spotify».
  Вход работает в Android-приложении и в программе на компьютере (не с телефона, открывшего ПК по Wi-Fi).
  Если Spotify отвечает «доступ запрещён» — добавьте свой e-mail в **User Management** приложения.
  Spotify может ограничивать приложения в режиме разработки (например, требовать Premium у владельца).
- **Прокси** — необязательно; если какой-то сервис у вас не открывается напрямую, можно указать
  свой прокси (`http://…` или `socks5://…`).

## Про «без VPN»
Яндекс Музыка, SoundCloud и API Spotify обычно доступны напрямую. Если сервис
недоступен в вашей сети, в поиске он покажет ошибку, а остальные продолжат работать.
Варианты: прокси в настройках или запуск MusicHub на сервере в другой стране (см. «Телефон»).

## Важно
Скачивайте треки для личного прослушивания. Яндекс Музыка через сторонние программы и
сохранение файлов нарушают пользовательские соглашения сервисов — используйте свой аккаунт
на свой риск. Защиту DRM программа не обходит.

## Известные ограничения
- YouTube всё чаще требует для yt-dlp внешний движок JavaScript (deno), и в России он замедлен —
  поэтому YouTube здесь только запасной источник. Основные — Яндекс Музыка и SoundCloud.
- В Android-версии нет кнопок управления на экране блокировки (будет в следующих версиях).

```

musichub/server.py           HTTP API (Starlette)
musichub/service.py          поиск, подбор звука, кэш, скачивание
musichub/matcher.py          сопоставление треков Spotify с другими источниками
musichub/tsdemux.py          извлечение звука из HLS/TS без ffmpeg
musichub/sources/            Яндекс, SoundCloud/YouTube (yt-dlp), Spotify
musichub/static/             интерфейс (HTML/CSS/JS, PWA)
musichub/android_main.py     запуск сервера внутри Android-приложения
android/                     Android-приложение (Kotlin + Chaquopy)
../.github/workflows/musichub.yml   автосборка .exe и .apk
```
